# T-008 — Doc aggregation (playbook = golden source of truth)

## Description
On a real multi-repo run, the per-repo `/docs` folders never got reconciled up into the playbook, so `playbook/docs` was an incomplete source of truth. Fix: aggregate **up** (not bilateral sync — which clobbers and forces every repo to carry every other repo's docs). Each repo's `/docs` is the single writer for its own facts; the playbook holds the project-wide authored docs plus a generated, SHA-stamped mirror of every repo. Session-start checks for drift and refreshes locally so an agent never reasons against a stale golden source.

## Acceptance criteria
- [x] `scripts/aggregate-docs.sh` — mirrors each manifest repo's `/docs` into `playbook/docs/repos/<name>/` (read-only, SHA-stamped); `--check` mode reports drift (exit 1 stale / 0 current). Reuses setup-workspace's manifest parse + dir validation. Idempotent; deletions propagate.
- [x] `scripts/test/test-aggregate-docs.sh` — 7 assertions (stale-when-missing, refresh builds mirror+stamp, current after refresh, stale after source change, additions mirrored, deletions propagate, no-manifest no-op). Wired into both CI pipelines.

- [x] Consensus-gate carve-out for `docs/repos/**` in `.githooks/commit-msg` + `scripts/ci-checks.sh` — generated mirror exempt (already gated in source repo); authored `/docs/*` still gated. Verified both directions.
- [x] `setup-workspace.sh` closing guidance + `ADOPTING.md` step 7 reference aggregation.
- [x] shellcheck clean; all three fixture suites pass.

## Out of scope
- Auto-committing the rollup from session-start (kept manual/PR — session refreshes locally + flags only, per the chosen non-blocking design).

## Notes
Chose **aggregate-up** over bilateral sync deliberately: bilateral mirroring has no conflict resolution (silent clobber — the likely cause of the original drift) and would force every repo to carry all repos' docs. Single-writer-per-fact + generated rollup eliminates both.
