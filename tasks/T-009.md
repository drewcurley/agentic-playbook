# T-009 — Executable specs and evidence-based gates (Tier 1)

## Description
Most of the starter's hard gates (`AGENTS.md` § 8) are prose plus attestation: an agent says the contract inventory is complete, that every acceptance criterion has a test, that all reviewers signed off. Nothing mechanical checks those claims. The goal is software that can be released with confidence with minimal human interaction, which requires those gates to be **verified by a machine from evidence**.

This parent task owns the plan and decision record ([ADR 0003](../docs/decisions/0003-executable-specs-and-evidence-gates.md)). The build is five subtasks, each a stage of a single `scripts/verify.sh` entrypoint.

**Stakeholders / personas:** the adopting team's engineers and their AI agents (who need one unambiguous definition of done), and the human approver (who needs to trust a green check without re-doing the review).

**Source request:** repo owner, 2026-10-26 — "recommend changes to take advantage of more mature spec-driven development approaches … release with confidence with minimal human interaction"; Tier 1 approved for planning.
