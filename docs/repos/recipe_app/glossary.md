# PantryPilot Glossary

**Status:** Tier 2 baseline, reconciled to current domain terms on 2026-11-19

- Pantry — the user’s tracked inventory of ingredients and supplies.
- Recipe hub — the authenticated home screen showing the user’s recipes.
- Shopping suggestion — a derived recommendation based on missing or low-stock ingredients.
- Low-stock threshold — the quantity at or below which a pantry item is suggested for purchase.
- Owner — the authenticated user associated with a row or Storage object.
- RLS — PostgreSQL row-level security policies enforced by Supabase.
- Static build — generated HTML, CSS, JavaScript, and assets served without a custom application server.
